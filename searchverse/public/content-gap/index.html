Content Gap & Topic Planner

Describe your brand, list your competitors, and it crawls every site — whole blogs, subdomains and any URLs you paste — finds each page's topic and main keyword, then asks Gemini which topics you should write next, each with its primary keyword.

2 · What to crawl

Whole-site mode starts at each home page, the folder you give and every sitemap URL, then follows internal links level by level until there are no new pages or it hits the page limit. It respects robots.txt. Pasted URLs are always crawled. Big sites take a few minutes, since pages are fetched 6 at a time.

Rankings — free sources (all optional)

Search Console (free) gives your real queries and positions. Export with the free “Search Analytics for Sheets” add-on, Looker Studio, or GSC → Performance → Export (a queries-only file works too). SearXNG is free, open-source metasearch you run yourself (one Docker command; enable the json format). The tool searches each main keyword and records where every site appears in the top 20 — positions are approximate and there's no search volume. Google Autocomplete (free) confirms each AI-picked keyword is something people really type. Keys are passed through to Google only, never stored on a server.

Save reports to Supabase (optional, free tier)

Keeps every report (crawl, rankings, topic map, AI ideas) so you can reopen it or compare over time. Run this once in Supabase → SQL editor:

create table cg_reports (
  id uuid primary key default gen_random_uuid(),
  created_at timestamptz not null default now(),
  brand text, domain text, competitors text[], pages int,
  data jsonb not null
);
alter table cg_reports enable row level security;
-- Anyone holding your anon key can read and write these rows. Keep the key private,
-- or switch these policies to authenticated users once you add Supabase Auth.
create policy "anon read" on cg_reports for select to anon using (true);
create policy "anon insert" on cg_reports for insert to anon with check (true);
